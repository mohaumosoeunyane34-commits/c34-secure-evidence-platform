# C34 Secure Evidence Platform — Installation

## Requirements

- Python 3
- Flask
- SQLite

## Installation

Create a virtual environment:

python3 -m venv .venv

Activate it:

source .venv/bin/activate

Install dependencies:

pip install -r requirements.txt

Start the application:

python backend/app.py

Open the address shown by the application in your browser.

## Security

Use this software only on systems and evidence you are authorized
to manage.

Do not place real passwords, secrets, private keys, or sensitive
evidence inside a public repository.
