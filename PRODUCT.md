# CANNIBAL 34 Secure Evidence Platform

## Community Edition

The Community Edition provides the core evidence-management
functionality for learning, testing, demonstrations, and
authorized small deployments.

### Included

- Officer accounts
- Incident management
- Evidence registration
- Evidence verification
- Basic custody tracking
- Basic audit logging
- SQLite database
- Web interface

## C34 Pro

The Pro Edition is intended for organizations requiring additional
features and commercial support.

### Planned Pro Features

- Advanced custody management
- Advanced audit reporting
- Administrative controls
- Report generation
- Data export
- Organization-specific configuration
- Deployment assistance
- Commercial licensing

## Security

Only use the platform with systems, information, and evidence
you are authorized to manage.

Never place real credentials, private keys, or sensitive evidence
in the public repository.

## Licensing

The Community Edition and Pro Edition are distributed under their
respective licenses. Commercial use of Pro features requires a
